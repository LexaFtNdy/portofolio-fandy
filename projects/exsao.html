Where it started

EXSAO began as the exam system for the KKMI Kemenag Surabaya joint tryout across 11 schools. One event, one web app, hundreds of students at once. It worked, and every school in the region had the same problem.

The wall

Schools need exams that stay up when everyone submits at once, keep questions from leaking, and keep answers when the school Wi-Fi drops. After the exam they need to know which questions were bad, not only who scored what.

One more

I turned it into a product schools rent monthly. Each school gets its own VPS and database, set up automatically after payment, usually in 10 to 20 minutes. Servers pull updates on a schedule, hold them while an exam is running, and dump the database before every migration. Around it sit locked-down desktop and Android clients, an AI assistant for teachers, and one admin panel that runs the business.

Four parts, one product

Exam server
Runs on each school's own VPS. Item analysis (difficulty, discrimination, distractors, KR-20), a rule-based engine that flags suspect answer keys and misconceptions and proposes remedial tests, answer key challenges with score recalculation, Word and PDF question import, and joint tryouts across schools with a combined ranking.

Laravel, Vue, Inertia.js, MySQL

Exam clients
Tauri desktop app and Capacitor Android app with kiosk mode and screenshot blocking. Attendance by a QR code that changes every 30 seconds, exam documents verifiable by QR, and answers recovered on the device when the connection drops.

Tauri, Rust, Capacitor, Vue

Lexa
A Claude API assistant that drafts questions, test blueprints and explanations, checks answer keys and grades essays, always for a teacher to review. Billed per use from prepaid credits.

Claude API, Laravel

Admin panel
One Filament app for EXSAO, SENCURA and Kaasir: orders, invoices, payments, licenses, app releases, bug reports and school server monitoring. Payments moved from Midtrans to Mayar without losing unpaid invoices.

Laravel, Filament, Mayar
