Featured Project

EXSAO.

Online Exam Platform for Schools

Built to survive hundreds of students clicking "Submit" in the same second — now rented to schools monthly, with one server per school.

The Origin

EXSAO started as the exam system for KKMI Kemenag Surabaya's joint tryout across 11 schools. One event, one web app, hundreds of students at once. It worked — and every school in the region had the same problem.

The Problem

Schools need exams that don't fall over when the whole class submits at once, don't leak questions, and don't lose answers when the school Wi-Fi drops. They also need to know which questions were bad after the exam, not just who scored what.

The Evolution

I turned it into a product schools rent monthly. Each school gets its own VPS and database, provisioned automatically after payment — usually in 10–20 minutes. Servers pull updates via cron, postpone them while an exam is running, and dump the database before each migration. Around it I built locked-down desktop and Android clients, an AI assistant for teachers, and one admin panel that runs the whole business.

The Ecosystem

Exam Server

Runs on each school's own VPS. Item analysis (difficulty, discrimination, distractors, KR-20), a rule-based engine that flags suspect answer keys and misconceptions and proposes remedial tests, answer key challenges with score recalculation, Word/PDF question import, and multi-school joint tryouts with a combined ranking.
