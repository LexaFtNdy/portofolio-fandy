Freelance Project

Teacher Profile.

Profile Site & Madrasah Administration

Started as a teacher's personal profile and CMS. Grew into the admin system the madrasah runs on — and later into SENCURA.

The Start

The brief was a profile site for a teacher: articles, rich text, and OG meta tags so every page shares cleanly on social media, all managed from an admin dashboard.

The Growth

Then the paperwork moved in. Teaching plans generated from the school calendar, a grade book with an offline input queue for flaky connections, report cards, QR attendance, and WhatsApp/Telegram notifications for parents. The madrasah's administration now runs on it.

What Came Next

Every school has the same paperwork, so I rebuilt the idea as a product: SENCURA, curriculum administration paired with EXSAO.

Tech Stack

Backend

NestJS API with Prisma on PostgreSQL, handling content, school administration data, and parent notifications.

NestJSPrismaPostgreSQL

Frontend

Public profile site in Nuxt with server-rendered OG tags, plus a separate admin app for content and school administration.

NuxtVue.jsTailwind CSS

Infrastructure

Containerized with Docker on a small VPS, Caddy as reverse proxy with automatic HTTPS, and scheduled backups.

Parent updates over WhatsApp and Telegram, QR codes for attendance.
