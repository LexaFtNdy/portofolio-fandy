It started as one teacher's profile site. It grew into the admin system the madrasah runs on, and later into SENCURA.

Role
Freelance developer
Status
Live at halopakaziz.com
Stack
NestJS, Prisma, PostgreSQL, Nuxt, Docker

The brief

A profile site for a teacher: articles, rich text, and Open Graph tags so every page shares cleanly on social media, all managed from an admin dashboard.

The wall

Then the paperwork moved in. Teaching plans from the school calendar, a grade book that has to keep working when the connection drops, report cards, attendance, and updates for parents.

One more

The grade book got an offline input queue, attendance went to QR codes, and parents get updates on WhatsApp and Telegram. The madrasah's administration runs on it now. Every school has the same paperwork, so I rebuilt the idea as a product: SENCURA, curriculum administration paired with EXSAO.

How it is built

Backend
NestJS API with Prisma on PostgreSQL, handling content, school administration data and parent notifications.

NestJS, Prisma, PostgreSQL

Frontend
Public profile site in Nuxt with server-rendered Open Graph tags, plus a separate admin app for content and school administration.

Nuxt, Vue, Tailwind CSS

Infrastructure
Docker on a small VPS, Caddy as the reverse proxy with automatic HTTPS, and scheduled backups.

Docker, Caddy, VPS

Integrations
Parent updates over WhatsApp and Telegram, and QR codes for attendance.

WhatsApp, Telegram Bot API, QR
