Feb 2026 to now, founder

EXSAO

Online exam platform rented to schools, one server per school, set up automatically after payment.

Problem
Students lose their connection in the middle of an exam, and servers want to update while one is running.
Fix
Answers are kept on the device and recovered when the line comes back. Updates wait until the exam ends, with a database dump before every migration. One server has run 600 students in a single exam.

Laravel, Vue, Inertia.js, MySQL, Tauri, Capacitor, Claude API, k6

Oct 2026 to now, freelance

Alleandro Honda Surabaya

Website for a Honda salesperson in Surabaya that shows every model with its current price.

Problem
The page was built with JavaScript and WebGL, so Google could barely read it. Prices also change every month.
Fix
Each of the 13 models gets its own plain HTML page, generated from one price file the salesperson edits. Change a price and the site updates itself.

Vanilla JS, WebGL2, Python, Playwright, Cloudflare Workers, GitHub Actions

Visit the live site

Jul 2026 to now, founder

Kaasir

Point of sale for shops and restaurants that keeps selling without internet, with a Flutter app for the owner.

Problem
A beta store with 8,000 products made every list lag, and local data hit the 5 MB browser storage cap.
Fix
Virtualized the cashier, catalog, inventory and history lists, and moved large local data to IndexedDB.

Tauri, React, Express, SQLite, Flutter

Oct 2026 to now, co-founder

Kiyura Top Up

Robux top-up store running on a single Cloudflare Worker, with the order queue handled through a Telegram bot.

Problem
A buyer can pay for a gamepass that does not exist, and a failed payment can hold stock for an order that never happens.
Fix
The gamepass is checked before payment. Stock is taken in one transaction and returned when payment fails.

Hono, Cloudflare D1 and R2, React, Telegram Bot API

Visit kiyura.my.id

Sep 2026 to now, co-founder

SwiftMu Tools

Paid SketchUp plugin with more than 20 modeling tools for architects, licensed by QRIS after a 7-day trial.

Problem
Updates download inside SketchUp on unreliable connections and can arrive half finished.
Fix
The updater checks each file against a SHA-256 hash and refuses partial downloads. The landing page rebuilds itself on every release.

Ruby, SketchUp API, Vue, Cloudflare Workers

Visit swiftmu.my.id
