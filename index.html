EXSAO — Online Exam Platform View Details →

Exam platform rented to schools monthly. Each school gets its own VPS and database, provisioned automatically after payment. Item analysis, a rule-based engine that flags suspect answer keys after each exam, multi-school joint tryouts, and Lexa — a Claude API assistant that drafts questions and grades essays for teacher review. Laravel Vue.js Inertia.js MySQL Tauri Capacitor Claude API

Laravel Vue.js MySQL Offline-First
Live Product — Fandika
03

Kaasir — Point of Sale

Point of sale for shops and restaurants, sold with license activation. Shift cash reports, customer credit, returns, kitchen display, table reservations, prepaid top-ups, and expiry-based stock. Sales run on local SQLite without internet; a Flutter owner app pairs with the cashier PC for reports. Virtualized every large list after a beta store with 8,000 products started to lag.

Tauri React Express SQLite Flutter
Live Product — Fandika
